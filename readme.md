# 🐾 Cãopanheiros - ONG (Projeto Web)

Este é o repositório do projeto de front-end para o site da Cãopanheiros, uma ONG fictícia dedicada ao resgate e adoção de animais. O projeto foi desenvolvido como parte da disciplina [Nome da Disciplina] e demonstra conceitos de HTML semântico, CSS moderno, JavaScript avançado (SPA, Templates) e práticas de produção.

## ✨ Visão Geral do Projeto

O site funciona como uma **Single Page Application (SPA)**, onde o conteúdo das seções (Início, Projetos, Cadastro) é carregado dinamicamente com JavaScript, sem a necessidade de recarregar a página.

### Funcionalidades Principais

* **Arquitetura SPA:** Navegação dinâmica entre páginas.
* **Templates JS:** O conteúdo HTML é gerado via JavaScript.
* **Validação de Formulário:** O formulário de cadastro possui validação de campos em tempo real.
* **Acessibilidade (WCAG AA):** O projeto inclui navegação por teclado, semântica ARIA, contraste de cores e um **Modo Escuro**.
* **Design Responsivo:** Construído com CSS Grid e Media Queries.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica.
* **CSS3:** Estilização moderna (CSS Grid, Flexbox, Variáveis CSS).
* **JavaScript (ES6+):** Manipulação do DOM, Modularização (import/export), Roteamento e Validação.
* **Git & GitHub:** Versionamento com GitFlow e Commits Semânticos.
* **Ferramentas:** VS Code, Live Server, TinyPNG (Otimização).
